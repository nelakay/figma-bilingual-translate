# Bilingual Translate — Figma Plugin

Translate text layers in-place between English and Chinese, directly inside Figma. Select any text on the canvas, pick a target language, and translate instantly.

## Features

- **Multi-select** — select a frame, component, or multiple text layers and translate them all at once
- **Auto-detect language** — automatically detects Chinese or English and suggests the opposite as the target
- **In-place replacement** — translates text directly in your design, preserving fonts and styles
- **Restore originals** — one click to revert all translations back to the original text
- **No API key required** — uses Lingva, an open-source Google Translate proxy

## How to Use

1. Open the plugin in Figma
2. Select any elements containing text (frames, groups, or individual text layers)
3. The plugin finds all text layers in your selection and shows a preview
4. Choose your target language from the dropdown (English or Chinese)
5. Click **Translate**
6. To undo, select the translated elements and click **Restore originals**

## Development

### Prerequisites

- Node.js
- Figma desktop app

### Setup

```bash
cd plugin
npm install
npm run build
```

### Load in Figma

1. Open Figma desktop app
2. Go to **Plugins > Development > Import plugin from manifest...**
3. Select `plugin/manifest.json`
4. Run the plugin from **Plugins > Development > Bilingual Translate**

### Project Structure

```
plugin/
  manifest.json      # Figma plugin config
  src/
    code.ts          # Plugin sandbox (Figma API, text node handling)
    ui.html          # Plugin UI (translation, language detection)
  dist/
    code.js          # Compiled output (generated by tsc)
```

## How It Works

- The plugin sandbox (`code.ts`) handles Figma API interactions: finding text nodes in the selection, loading fonts, and replacing text content
- The UI iframe (`ui.html`) handles translation via Lingva's REST API and manages the user interface
- Original text is stored as plugin data on each text node, enabling the restore feature
- Font preservation: before replacing text, the plugin loads all fonts used in the text node to avoid font errors

## Translation API

Uses [Lingva Translate](https://github.com/thedaviddelta/lingva-translate), an open-source alternative frontend for Google Translate. No API keys, no accounts, no usage limits.
